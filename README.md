# JP Builds

I build custom software, workflow automation, APIs, internal tools, and AI-assisted systems.

Since 2019, I’ve worked across frontend, backend, databases, and cloud infrastructure. Most of my client and product code lives in private repositories.

## What I build

- Custom web applications and internal tools
- Workflow automation and system integrations
- Reliable APIs, webhooks, queues, retries, and background jobs
- AI-assisted email, document, research, and operations workflows with human review
- Cloud infrastructure and deployment tooling with AWS and Docker

I work with React, TypeScript, Node.js, and PostgreSQL. I’ve also built with Angular and Vue, and used Python with Flask and FastAPI.

## How I work

I care about what happens after the happy path. If a request fails or gets retried, the team should be able to tell whether anything changed and decide what to do next. I write code with the next person who’ll maintain it in mind.

I work with clients to understand what needs to change and review the result with them as the work takes shape. On a team, I explain why a change is needed in the pull request and work through feedback with other engineers. I run the relevant tests and check CI before shipping.

## Current focus

I founded LBOS and built it as a solo developer. It’s an operating system for local businesses. A team can take a customer request from intake to a quote, schedule the work, and send an invoice, all tied to the same customer record.

I built the web app, APIs, data models, and integrations behind those workflows. An operator can use Ask LBOS to draft a return visit, adjust the time in a follow-up message, and review the details before confirming the change.
